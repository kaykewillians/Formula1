# PIT WALL — GP DE SÃO PAULO

Projeto desenvolvido com **HTML5 e CSS3**, inspirado no universo da Fórmula 1 e no Grande Prêmio de São Paulo, realizado no Autódromo de Interlagos.

A proposta é criar uma página moderna e responsiva para apresentar informações sobre pilotos, classificação e venda ilustrativa de ingressos para uma corrida.

---

## 1. Objetivo do projeto

Desenvolver uma página web utilizando HTML e CSS, colocando em prática conceitos de estruturação, estilização e responsividade.

O projeto busca reproduzir uma interface esportiva com identidade visual inspirada nas equipes e nos eventos automobilísticos.

## 2. Funcionalidades e seções

**Cabeçalho:** navegação entre as principais áreas do site.

**Banner principal:** apresentação do GP de São Paulo.

**Estatísticas:** informações sobre voltas, quilometragem e curvas.

**Grid de pilotos:** apresentação dos pilotos e suas respectivas equipes.

**Classificação:** tabela ilustrativa com posições, vitórias e pontuações.

**Ingressos:** apresentação dos setores disponíveis e seus preços.

**Formulário:** interface para preenchimento de dados de reserva.

**Responsividade:** adaptação do layout para computadores, tablets e celulares.

## 3. Tecnologias utilizadas

## 5. Como executar o projeto

1. Baixe ou clone o repositório.
2. Abra a pasta do projeto no Visual Studio Code.
3. Localize o arquivo `index.html`.
4. Abra o arquivo no navegador ou utilize a extensão Live Server.
5. Navegue pelas seções da página.

## 6. Identidade visual

O projeto utiliza uma identidade visual inspirada no automobilismo, com predominância das seguintes cores:

**Preto:** fundo principal da página.

**Vermelho:** botões, destaques e elementos de competição.

**Branco:** textos e elementos de contraste.

**Cinza:** informações complementares e divisões.

A interface utiliza fontes personalizadas para transmitir uma aparência esportiva e moderna.

## 7. Observações

Este projeto possui finalidade educacional e foi desenvolvido para praticar HTML5 e CSS3.

As informações de classificação, pontuação e valores de ingressos são ilustrativas.

O formulário e os filtros representam elementos visuais da interface e ainda não possuem integração com banco de dados ou sistema de processamento de reservas.
